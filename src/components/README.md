# Paradise Nursery

Paradise Nursery is an online plant shopping application built using React and Redux.

## Project Description

Paradise Nursery allows users to browse different categories of houseplants and add plants to a shopping cart.

## Features

- Home page with Paradise Nursery branding
- Plant listing page
- Three plant categories
- Multiple plants in each category
- Plant name, image and price
- Add to Cart functionality
- Dynamic cart item count
- Increase and decrease quantity
- Delete items from cart
- Total price calculation
- Checkout option
- Continue Shopping option
- About Us page

## Technologies Used

- React
- Redux Toolkit
- React Router
- JavaScript
- CSS
- Vite
